1. Introduction to Reinforcement Learning

1.1 What is RL?

Reinforcement Learning (RL) is the area of ML where an agent learns to take actions in an environment so as to maximize cumulative reward, by interacting with the environment and receiving scalar reward signals. There is no labelled "correct action"; the agent learns by trial and error.

RL vs other ML paradigms

SupervisedUnsupervisedRL
Data$(x,y)$ pairs$x$ onlySequences of $(s,a,r,s')$ from interaction
FeedbackCorrect labelNoneScalar reward, often delayed
GoalGeneralize input→outputDiscover structureMaximize return over time
Active?PassivePassiveActive — agent chooses what to try

Distinctive challenges

  • Delayed reward / credit assignment — which action long ago was responsible?
  • Exploration vs exploitation — try new actions or use the best known?
  • Non-stationarity — as the agent improves, the data distribution shifts.
  • Sequential decisions — current action affects future states (closed-loop).

Examples

  • Game-playing: Atari, Go, Chess (AlphaGo), Poker.
  • Robotics: locomotion, manipulation.
  • Autonomous driving (planning, control).
  • Resource management: data-centre cooling (DeepMind).
  • Recommendation, ad bidding, finance (with caution).
  • Dialogue systems, RLHF for LLMs.

1.2 Elements of an RL System

Four key elements (plus environment):
  • Policy $\pi$ — agent's behaviour. Maps state → action (deterministic $\pi(s)=a$ or stochastic $\pi(a|s)$).
  • Reward signal $R_t$ — scalar from environment defining what's good right now. Defines the goal.
  • Value function $v_\pi(s)$ or $q_\pi(s,a)$ — expected total future reward from state (or state-action) under $\pi$. Estimates the long-term desirability.
  • Model of the environment (optional) — predicts $P(s',r|s,a)$. Lets the agent simulate without acting.

Characteristics

  • Reward is given by the environment; the agent cannot change it.
  • Values are estimates learned from experience — they're harder to obtain but more central than rewards.
  • RL methods are classified as model-based vs model-free based on whether they use/learn a model.

1.3 Example — RL for Tic-Tac-Toe

Classical RL example (Sutton & Barto Ch.1):

  1. Build a table $V(s)$ for every possible board state. Initialize: wins=1.0, losses=0.0, other states=0.5.
  2. Play many games against an opponent. Most of the time, pick the move leading to state with highest $V(s)$ (greedy). Occasionally, explore a random move.
  3. After each greedy move, update the prior state's value toward the new state's value (TD update): $$V(S_t) \leftarrow V(S_t) + \alpha\,[V(S_{t+1}) - V(S_t)]$$
  4. Over time, values back-propagate from terminal wins → earlier states → optimal play.

This illustrates: states, policy (greedy vs explore), value function, bootstrapping/TD learning — all without an explicit model.

1.4 Historical Background (highlights)

  • Trial-and-error learning — Thorndike's "Law of Effect" (1911), Skinner.
  • Optimal control / dynamic programming — Bellman 1957.
  • Temporal-difference learning — Samuel's checkers (1959), Sutton (1988).
  • Q-learning — Watkins 1989.
  • Policy gradient — REINFORCE, Williams 1992; PG theorem, Sutton 1999.
  • TD-Gammon — Tesauro 1992 (RL + NN beats world-class backgammon).
  • Deep RL era — DQN on Atari (Mnih et al. 2013/2015), AlphaGo 2016, AlphaGo Zero 2017, OpenAI Five, AlphaStar, MuZero, RLHF (2022).

2. Multi-Armed Bandits (MAB)

2.1 Motivation & Problem

The $k$-armed bandit problem: you face $k$ slot-machine levers ("arms"); each pull of arm $a$ gives a reward drawn from an unknown stationary distribution with mean $q_*(a)$. Goal: maximize total reward over $T$ steps. There is no state — only an action and a reward — so it isolates the exploration vs exploitation dilemma in pure form.

Why care?

  • Building block — full RL is a "contextual / sequential bandit".
  • Applications: A/B testing, clinical trials, online ads, recommender exploration.

2.2 Action-Value Estimation (Stationary)

Sample-average estimate after $n-1$ rewards from action $a$: $$Q_n = \frac{R_1 + R_2 + \cdots + R_{n-1}}{n-1}$$ Incremental update (constant memory): $$Q_{n+1} = Q_n + \frac{1}{n}\,[R_n - Q_n]$$

Numeric. Arm A rewards so far: 2, 4, 6. $Q_4=(2+4+6)/3=4$. New reward 8 → $Q_5 = 4 + (1/4)(8-4) = 5$. Matches $(2+4+6+8)/4=5$. ✓

2.3 Non-stationary Problem

If $q_*(a)$ drifts over time, the equal-weight average lags. Use exponential recency-weighted average with constant step-size $\alpha\in(0,1]$: $$Q_{n+1} = Q_n + \alpha\,[R_n - Q_n]$$ This gives weight $\alpha(1-\alpha)^{n-i}$ to the $i$-th past reward — recent rewards dominate.

2.4 Exploration vs Exploitation

ε-greedy

With probability $1-\epsilon$ pick the greedy action $\arg\max_a Q(a)$; with probability $\epsilon$ pick a uniform random action.

Optimistic initial values

Initialize $Q(a)$ high (e.g. +5). The agent gets disappointed when reward is lower → tries other actions → built-in exploration. Works only in stationary settings.

Upper Confidence Bound (UCB1)

Pick the action with the highest optimistic estimate: $$A_t = \arg\max_a\!\left[ Q_t(a) + c\sqrt{\frac{\ln t}{N_t(a)}} \right]$$ where $N_t(a)$ = times $a$ chosen so far. The square-root bonus shrinks for well-tried actions and grows for under-tried ones, achieving logarithmic regret.
UCB numeric. $t=100,c=2$. Arm A: $Q=5,N=80 \Rightarrow$ UCB $=5+2\sqrt{\ln100/80}=5+2(0.240)=5.48$. Arm B: $Q=4.5, N=20 \Rightarrow 4.5+2\sqrt{\ln100/20}=4.5+2(0.480)=5.46$. Pick A — barely. As $N_A$ grows, B's bonus eventually overtakes if its $Q$ stays close.

2.5 Gradient Bandit Algorithm (Stochastic Gradient Ascent)

Learn preferences $H_t(a)$; convert to a soft-max policy: $$\pi_t(a) = \frac{e^{H_t(a)}}{\sum_b e^{H_t(b)}}$$ Update after observing $R_t$: $$H_{t+1}(A_t) = H_t(A_t) + \alpha (R_t - \bar R_t)(1 - \pi_t(A_t))$$ $$H_{t+1}(a) = H_t(a) - \alpha(R_t - \bar R_t)\pi_t(a)\quad \forall a\ne A_t$$ where $\bar R_t$ is a running mean (baseline). This is exactly stochastic gradient ascent on expected reward $\mathbb{E}[R_t]$ — preview of policy gradient.

2.6 Associative Search (Contextual Bandit)

Each round, the agent sees a context $x_t$ (e.g. user profile) before choosing an arm. The optimal action depends on context. This is the bridge between bandits (no state) and full RL (state with dynamics). Used in personalised recommendations.

3. Markov Decision Processes (MDPs)

3.1 Agent–Environment Interaction

A finite MDP is a tuple $\langle \mathcal{S},\mathcal{A},P,R,\gamma\rangle$ where
  • $\mathcal{S}$ = set of states,
  • $\mathcal{A}$ = set of actions,
  • $P(s'|s,a)$ = transition probability,
  • $R(s,a,s')$ or $r(s,a) = \mathbb{E}[R_{t+1}|S_t=s,A_t=a]$ = reward function,
  • $\gamma\in[0,1]$ = discount factor.
The Markov property: future state depends only on the current state and action, not the past history.

Time step $t$: agent observes $S_t$, takes action $A_t$, receives reward $R_{t+1}$, and transitions to $S_{t+1}$. The trajectory is $S_0,A_0,R_1,S_1,A_1,R_2,\dots$.

Examples

  • Grid-world: states = grid cells, actions = N/S/E/W, reward = −1 each step, terminal at goal.
  • Inventory management: state = stock level, action = how much to order.
  • Tic-tac-toe: states = board configs, actions = legal moves.

3.2 Goals, Rewards & Returns

Reward hypothesis. All of what we mean by goals and purposes can be well thought of as the maximization of the expected value of the cumulative sum of a received scalar signal (Sutton).

Return

Episodic: $G_t = R_{t+1}+R_{t+2}+\dots+R_T$.
Continuing (with discount): $G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$.
Unified definition uses a terminal absorbing state for episodic case.

$\gamma$ small ⇒ myopic; $\gamma\to 1$ ⇒ far-sighted. $\gamma$ also ensures convergence in infinite-horizon problems.

Return numeric. Rewards $R_1=1,R_2=2,R_3=3,R_4=4$, $\gamma=0.5$, episode ends after $T=4$.
$G_0 = 1 + 0.5(2)+0.25(3)+0.125(4) = 1+1+0.75+0.5 = 3.25$.

3.3 Policy and Value Functions

A policy $\pi(a|s)$ = probability of taking action $a$ in state $s$.
State-value: $v_\pi(s)=\mathbb{E}_\pi[G_t|S_t=s]$.
Action-value: $q_\pi(s,a)=\mathbb{E}_\pi[G_t|S_t=s,A_t=a]$.

3.4 Bellman Equations

Recursive consistency: value of a state equals expected immediate reward plus discounted value of next state.

$$v_\pi(s) = \sum_a \pi(a|s)\sum_{s',r} P(s',r|s,a)[r + \gamma v_\pi(s')]$$ $$q_\pi(s,a) = \sum_{s',r} P(s',r|s,a)\left[r + \gamma\sum_{a'} \pi(a'|s')\,q_\pi(s',a')\right]$$
Tiny MDP. Two states A (non-terminal) and T (terminal). Only one action; from A, go to T with prob 1, reward 10. $\gamma=0.9$.
$v(A)= 10 + 0.9\cdot v(T)=10+0=10$.

3.5 Optimal Policy and Optimal Value Functions

$\pi^* \ge \pi'$ iff $v_{\pi^*}(s) \ge v_{\pi'}(s)\ \forall s$. There always exists at least one deterministic optimal policy.

Bellman optimality equations (non-linear due to max): $$v_*(s) = \max_a \sum_{s',r} P(s',r|s,a)[r+\gamma v_*(s')]$$ $$q_*(s,a) = \sum_{s',r}P(s',r|s,a)[r+\gamma \max_{a'} q_*(s',a')]$$ $\pi^*(s) = \arg\max_a q_*(s,a)$.

4. Dynamic Programming (DP)

DP methods assume a known MDP ($P,R$) and compute value functions/optimal policies via Bellman updates. They are the theoretical foundation; later methods (MC, TD) drop the model requirement.

4.1 Iterative Policy Evaluation

Compute $v_\pi$ for a fixed policy by sweeping all states and applying the Bellman equation as an update rule: $$v_{k+1}(s) = \sum_a \pi(a|s)\sum_{s',r}P(s',r|s,a)[r+\gamma v_k(s')]$$ Converges to $v_\pi$ as $k\to\infty$.

4.2 Policy Improvement

Given $v_\pi$, construct a greedy policy $\pi'$: $$\pi'(s) = \arg\max_a \sum_{s',r}P(s',r|s,a)[r+\gamma v_\pi(s')]$$ The policy improvement theorem guarantees $v_{\pi'} \ge v_\pi$, strictly improving unless already optimal.

4.3 Policy Iteration

Initialize π arbitrarily. Repeat: 1. Policy Evaluation: compute v_π to convergence. 2. Policy Improvement: π ← greedy(v_π). Until π is stable.

Each step monotonically improves the policy; finite MDPs → converges in finitely many steps.

4.4 Value Iteration

Truncate policy evaluation to a single sweep, folding the max in: $$v_{k+1}(s) = \max_a \sum_{s',r}P(s',r|s,a)[r+\gamma v_k(s')]$$ Until $\|v_{k+1}-v_k\|_\infty < \theta$. Then derive policy greedily.

VI numeric. 3-state MDP. States A,B,C; C terminal with $v(C)=0$. Action set yields deterministic transitions: A→B reward 1, B→C reward 5, A→C reward 0. $\gamma=0.9$.
Init $v=0$ everywhere.
Iter 1: $v(B)=5+0.9\cdot 0=5$. $v(A)=\max(1+0.9(0), 0+0.9(0))=1$.
Iter 2: $v(A)=\max(1+0.9(5), 0+0.9(0))=5.5$. $v(B)=5$.
Converged. Optimal: A→B→C, return 5.5.

4.5 Generalized Policy Iteration (GPI)

GPI = any interleaving of policy evaluation (toward $v_\pi$) and policy improvement (toward greedy). Both processes "compete and cooperate"; their fixed point is the optimal policy and value. Nearly all RL algorithms can be seen as GPI.

4.6 Efficiency of DP

  • Each sweep is $O(|\mathcal{S}|^2|\mathcal{A}|)$ — polynomial in $|S|,|A|$ but the state space is often exponential ("curse of dimensionality").
  • Asynchronous DP — update states in arbitrary order; useful when only some states matter.
  • DP bootstraps (uses estimates to update estimates) — key idea reused by TD.
  • Requires full model $P,R$ — MC and TD do not.

5. Monte Carlo (MC) Methods

MC methods learn directly from sampled episodes of experience — no model needed. Estimate $v_\pi(s)$ as the average return following visits to $s$ in many episodes.

Requirements

  • Episodes must terminate.
  • Need an exploring policy to visit all states/actions (or use ES/off-policy).

5.1 First-Visit vs Every-Visit MC Prediction

  • First-visit MC: average returns following the first visit to $s$ in each episode.
  • Every-visit MC: average returns following every visit. Both converge to $v_\pi(s)$.
Repeat for many episodes: Generate episode S0,A0,R1,...,S_T following π. G ← 0 For t = T-1, ..., 0: G ← γG + R_{t+1} if first-visit and S_t hasn't appeared before in this episode: Returns(S_t).append(G) V(S_t) ← average of Returns(S_t)
MC numeric. Episode: S=A,B,C,A,T. Rewards 1,2,3,4. $\gamma=1$.
Returns: $G_3=4$ (from A→T). $G_2=3+4=7$ (from C). $G_1=2+7=9$. $G_0=1+9=10$.
First-visit V(A)=10 (first occurrence), V(B)=9, V(C)=7. Every-visit V(A)=(10+4)/2=7.

5.2 MC Control — Exploring Starts (ES) & ε-soft

To find optimal policy without a model, we estimate $q_\pi(s,a)$ and act greedily. Two ways to ensure exploration:

  • Exploring Starts: each episode begins at a random (s,a) with non-zero probability. Impractical in real environments.
  • ε-soft policies: $\pi(a|s)\ge \epsilon/|A|$ for all $a$. On-policy MC control improves over ε-soft policies; converges to best ε-soft policy.

5.3 Off-Policy MC — Importance Sampling

Learn target policy $\pi$ from data generated by behaviour policy $b$ (must cover $\pi$): $$\rho_{t:T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k|S_k)}{b(A_k|S_k)},\quad V(s) = \frac{\sum \rho\cdot G}{\sum 1}\text{ (ordinary IS)}$$ or weighted IS (lower variance, biased). Off-policy MC enables learning from logs, demonstrations, prior policies.

5.4 Incremental MC

Avoid storing all returns by incremental mean: $$V(S_t) \leftarrow V(S_t) + \frac{1}{N(S_t)}[G_t - V(S_t)]$$ With constant $\alpha$ for non-stationary problems: $V(S_t)\leftarrow V(S_t)+\alpha[G_t - V(S_t)]$.

MC strengths & weaknesses

  • + Model-free, easy to implement, unbiased.
  • + Focuses computation on visited states.
  • − High variance; requires full episodes; not for continuing tasks (without modifications).

6. Temporal-Difference (TD) Learning

TD learning combines MC (learn from experience) with DP (bootstrap from estimates). It updates $V$ after every step, not at episode end.

6.1 TD(0) Prediction

$$V(S_t)\leftarrow V(S_t)+\alpha\Bigl[\underbrace{R_{t+1}+\gamma V(S_{t+1})}_{\text{TD target}} - V(S_t)\Bigr]$$

The bracketed quantity is the TD error $\delta_t = R_{t+1}+\gamma V(S_{t+1})-V(S_t)$.

6.2 SARSA — On-Policy TD Control

Estimate $q_\pi$ and improve $\pi$ (ε-greedy). Update uses the actually taken next action $A_{t+1}$: $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\bigl[R_{t+1}+\gamma Q(S_{t+1},A_{t+1}) - Q(S_t,A_t)\bigr]$$ The name comes from the tuple $(S,A,R,S',A')$ used in the update.

6.3 Q-Learning — Off-Policy TD Control

$$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\bigl[R_{t+1}+\gamma\,\max_{a'} Q(S_{t+1},a') - Q(S_t,A_t)\bigr]$$

Update uses the greedy next action regardless of which was actually taken. Learns $q_*$ directly. Off-policy ⇒ can learn from any behaviour data.

Q-learning step. $S=s_1,A=a_1,R=1,S'=s_2,\gamma=0.9,\alpha=0.5$. Current $Q(s_1,a_1)=2$, $\max_{a'}Q(s_2,a')=5$.
TD target $=1+0.9(5)=5.5$. TD error $=5.5-2=3.5$. New $Q(s_1,a_1)=2+0.5(3.5)=3.75$.

SARSA vs Q-Learning intuition (Cliff Walking)

On the famous cliff-walking grid: SARSA learns a safer path (because the ε-greedy behaviour occasionally falls off the cliff and SARSA accounts for that during evaluation). Q-learning learns the optimal path along the cliff edge but its online return is worse due to occasional falls.

6.4 Expected SARSA

Replace the sampled next $Q$ by its expectation under $\pi$: $$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\Bigl[R_{t+1}+\gamma\sum_{a'} \pi(a'|S_{t+1})Q(S_{t+1},a') - Q(S_t,A_t)\Bigr]$$ Lower variance than SARSA. Generalises both SARSA ($\pi$=behaviour) and Q-learning ($\pi$=greedy).

6.5 N-Step TD Prediction

Use a return that looks $n$ steps ahead, then bootstraps: $$G_{t:t+n} = R_{t+1}+\gamma R_{t+2}+\dots+\gamma^{n-1}R_{t+n}+\gamma^n V(S_{t+n})$$ $$V(S_t)\leftarrow V(S_t)+\alpha[G_{t:t+n}-V(S_t)]$$ $n=1$ → TD(0); $n=\infty$ → MC. Intermediate $n$ often best; smoothed continuously by TD($\lambda$) using eligibility traces.

6.6 N-Step SARSA & Off-Policy N-Step SARSA

Generalise SARSA with $n$-step returns: $$G_{t:t+n} = \sum_{k=0}^{n-1}\gamma^k R_{t+k+1} + \gamma^n Q(S_{t+n},A_{t+n})$$ Off-policy variant multiplies by importance-sampling ratio $\prod_{k=t+1}^{t+n-1} \frac{\pi(A_k|S_k)}{b(A_k|S_k)}$.

6.7 Tree Backup Algorithm

An off-policy $n$-step method without importance sampling. The target backs up expected values over all actions at each step using $\pi$, while continuing along the taken trajectory: $$G_{t:t+n}^\text{tree} = R_{t+1}+\gamma\sum_{a\ne A_{t+1}}\pi(a|S_{t+1})Q(S_{t+1},a)+\gamma\pi(A_{t+1}|S_{t+1})G_{t+1:t+n}^\text{tree}$$

Lower variance than IS-based off-policy methods, but biased toward target policy.

7.2 Value-Based vs Policy-Based vs Actor–Critic

  • Value-based — learn $V$ or $Q$, policy is implicit (greedy on $Q$). E.g. Q-learning, DQN.
  • Policy-based — directly parameterise $\pi_\theta$, optimise expected return. E.g. REINFORCE, PG. Better for continuous actions / stochastic policies.
  • Actor–Critic — combine: actor=policy, critic=value function. Lower variance than pure PG; faster than pure value-based for complex action spaces.

7.3 On-Policy vs Off-Policy

An on-policy method evaluates/improves the same policy it uses to act (SARSA, REINFORCE, A2C, PPO). An off-policy method evaluates/improves a target policy different from the behaviour (Q-learning, DQN, DDPG, SAC). Off-policy enables reuse of past experience (replay), demonstrations, and exploration policies.

7.4 Deep Learning as a Function Approximator

Tabular methods scale as $|S|,|A|$ — useless for Atari pixels or robot states. Replace tables with neural nets $V_\theta(s)$, $Q_\theta(s,a)$, $\pi_\theta(a|s)$. Gradient-based updates of $\theta$. Hyperparameters: architecture, optimiser, target networks, replay.

Trade-off: function approximation breaks tabular convergence guarantees — instability is a central topic (§8.4).

8. Value-Based Deep RL

8.1 Function Approximation

Estimate $\hat v(s,\mathbf w)$ or $\hat q(s,a,\mathbf w)$ parameterised by weights $\mathbf w$. Minimise expected squared error vs target. Linear or non-linear (NN).

8.2 Feature Construction — Tile Coding

Tile coding = a sparse, coarse-coded binary feature representation. Overlay multiple tilings (offsets of a grid) over the state space; each tiling partitions space into tiles; one feature per tile, equal to 1 if state falls in it, else 0. The active feature vector is sparse (one tile per tiling), enabling fast linear updates.
  • Captures generalisation between nearby states.
  • Hyperparams: number of tilings, tile width, offsets.
  • Asymmetric tile coding — different tile widths along different dimensions (e.g. fine in velocity, coarse in position).

8.3 Linear Function Approximation & Semi-Gradient TD

$\hat v(s,\mathbf w)= \mathbf w^\top \phi(s)$.
Semi-gradient TD(0) update (treat target as constant for gradient): $$\mathbf w\leftarrow \mathbf w + \alpha[R+\gamma \mathbf w^\top \phi(S') - \mathbf w^\top \phi(S)]\,\phi(S)$$ "Semi"-gradient because we ignore the dependence of the target on $\mathbf w$. Converges under on-policy linear FA.

8.4 Off-Policy Function Approximation — TD Divergence ("Deadly Triad")

Combining all three: function approximation, bootstrapping, and off-policy learning ⇒ can diverge. This is Sutton's "deadly triad". Classic counter-example: Baird's counter-example shows TD weights can explode.

Mitigations: target networks, replay buffers (DQN), gradient-TD methods (GTD, GTD2, TDC), constrained step sizes, careful exploration.

8.5 Deep Q-Network (DQN, Mnih et al. 2015)

$Q_\theta(s,a)$ — a CNN over screen pixels in the Atari setting.

Loss

$$\mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s')\sim \mathcal{D}}\left[\left(r + \gamma\max_{a'} Q_{\theta^-}(s',a') - Q_\theta(s,a)\right)^2\right]$$

Key tricks

  • Experience Replay — store transitions $(s,a,r,s')$ in a buffer $\mathcal D$; sample mini-batches uniformly. Breaks correlations + reuses data.
  • Target Network $\theta^-$ — a slowly updated copy of $\theta$ used to compute the bootstrap target. Stabilises learning by decoupling target.
  • Reward clipping, frame skipping, ε-greedy schedule.
  • Input: stack of 4 frames (gives velocity); output: one Q value per action.
Initialize Q_θ, target Q_{θ-}=Q_θ, replay D. For each step: Take a = ε-greedy(Q_θ(s,·)). Observe (r, s'); store (s,a,r,s') in D. Sample minibatch from D. Compute y = r + γ max_a' Q_{θ-}(s',a'). Update θ by SGD on (y - Q_θ(s,a))^2. Every C steps: θ- ← θ.

8.6 Double DQN (van Hasselt 2015)

Standard Q-learning is biased upward because the same network selects and evaluates the max action — noise gets propagated. Double DQN decouples them: $$y = r + \gamma\, Q_{\theta^-}\!\bigl(s',\ \arg\max_{a'} Q_\theta(s',a')\bigr)$$ Online net picks the action; target net evaluates it. Significantly reduces over-estimation bias.

8.7 Rainbow (Hessel et al. 2017)

Combines 6 independent DQN improvements; all of them together set SOTA at the time:

  1. Double DQN — over-estimation fix.
  2. Prioritised Experience Replay — sample transitions with high TD error more often.
  3. Dueling networks — separate streams for $V(s)$ and advantage $A(s,a)$, recombine: $Q=V+A-\text{mean}(A)$.
  4. Multi-step (n-step) returns — use $n$-step target instead of 1-step.
  5. Distributional RL (C51) — learn the distribution of returns, not just the mean.
  6. Noisy Nets — parametric noise on weights for exploration, instead of ε-greedy.

9. Policy Gradient Methods

9.1 Why Policy Gradients

  • Naturally handle stochastic policies.
  • Work in continuous action spaces (no $\arg\max$ over millions of actions).
  • Smooth changes in $\theta$ → smooth changes in $\pi$ → better convergence properties.
  • Can encode constraints via parameterisation.

9.2 Policy Gradient Theorem

For a parameterised policy $\pi_\theta(a|s)$ and performance measure $J(\theta)=v_{\pi_\theta}(s_0)$: $$\nabla_\theta J(\theta) \propto \sum_s d_{\pi}(s)\sum_a q_\pi(s,a)\nabla_\theta \pi_\theta(a|s)$$ Equivalently: $$\nabla_\theta J(\theta) = \mathbb{E}_{\pi}\bigl[\nabla_\theta \log\pi_\theta(A|S)\,Q_\pi(S,A)\bigr]$$ No gradient of the (unknown) state distribution appears — the "magic" of PG.

9.3 REINFORCE (Monte-Carlo Policy Gradient, Williams 1992)

Sample episodes, then update with the MC return: $$\theta\leftarrow \theta + \alpha\,\gamma^t\,G_t\,\nabla_\theta \log\pi_\theta(A_t|S_t)$$

Repeat: Generate episode S0,A0,R1,..,S_{T-1},A_{T-1},R_T with π_θ. For t = 0,..,T-1: G_t = Σ_{k=t}^{T-1} γ^{k-t} R_{k+1} θ ← θ + α γ^t G_t ∇_θ log π_θ(A_t|S_t)

Unbiased but very high variance.

9.4 REINFORCE with Baseline

Subtract a baseline $b(s)$ (any function of state) from the return — keeps the gradient unbiased, reduces variance: $$\theta\leftarrow \theta + \alpha\,(G_t - b(S_t))\,\nabla_\theta \log\pi_\theta(A_t|S_t)$$ A common choice is $b(s)=\hat v_w(s)$, learned simultaneously by minimising $[G_t - \hat v_w(s)]^2$.

9.5 Actor–Critic Methods

Two parameterised networks:
  • Actor $\pi_\theta(a|s)$ — chooses actions.
  • Critic $\hat v_w(s)$ or $\hat q_w(s,a)$ — evaluates them via bootstrapped TD.
Use the TD error $\delta = R + \gamma\hat v_w(S') - \hat v_w(S)$ as a low-variance estimate of the advantage: $$\theta\leftarrow \theta + \alpha_\theta\,\delta\,\nabla_\theta \log\pi_\theta(A|S)$$ $$w \leftarrow w + \alpha_w\,\delta\,\nabla_w \hat v_w(S)$$

Variants: A2C (synchronous), A3C (asynchronous), DDPG (continuous deterministic), TD3, SAC (max-entropy), PPO (clipped surrogate, see §12).

9.6 PG for Continuing Tasks (Average Reward)

For non-episodic problems we use average reward $r(\pi)=\lim_{T\to\infty}\frac{1}{T}\mathbb{E}[\sum R_t]$ and differential value $v_\pi(s)=\mathbb{E}[\sum_k (R_{t+k}-r(\pi))|S_t=s]$. Update with TD error $\delta = R - \bar R + v(S')-v(S)$. Removes the need for $\gamma$.

10. Model-Based Deep RL

10.1 UCB Action Selection (Recap, in a tree)

In planning, at each decision node, balance exploration of less-tried actions with exploitation of high-value ones using the UCB1 formula. This is the engine inside MCTS: $$a^* = \arg\max_a\left[Q(s,a) + c\sqrt{\frac{\ln N(s)}{N(s,a)}}\right]$$

10.2 Monte-Carlo Tree Search (MCTS)

An anytime planning algorithm that grows a search tree from the current state. Each iteration runs four steps:
  1. Selection — descend from root using a tree policy (e.g. UCB) until reaching a leaf.
  2. Expansion — add a new child node.
  3. Simulation (Rollout) — play out from the new node using a default/random policy until terminal.
  4. Backpropagation — update visit counts $N$ and value estimates $Q$ up the tree.
After many iterations, choose the most visited action at the root.

10.3 AlphaGo Zero (Silver et al. 2017)

  • Tabula-rasa: no human games, only self-play.
  • A single neural network outputs both a policy $p(a|s)$ and a value $v(s)$.
  • MCTS uses the network for selection (PUCT) and skips rollouts — uses $v$ directly.
  • The improved MCTS policy is the target for supervised training of $p$; the game result is the target for $v$.
  • Surpasses AlphaGo Lee in 3 days; mastered Go from scratch.

10.4 MuZero (Schrittwieser et al. 2020)

MuZero learns its own latent model — no need to know the game rules. Three networks:
  • Representation $h: o \to s$ (encode observations to latent state).
  • Dynamics $g: (s,a)\to (s',r)$ in latent space.
  • Prediction $f: s \to (p, v)$ — policy and value.
MCTS planning happens entirely in latent space. Achieves SOTA on Go, chess, shogi, and Atari with one architecture.

10.5 PlaNet (Hafner et al. 2019)

  • Learn a Recurrent State-Space Model (RSSM) that predicts latent dynamics and rewards from images.
  • Plan with the model using CEM (Cross-Entropy Method) to optimise action sequences.
  • Solves continuous-control tasks from pixels with far fewer interactions than model-free counterparts.
  • Successors: Dreamer, DreamerV2/V3 — train a policy inside the learned world model.

11. Imitation Learning

11.1 What & Why

Imitation Learning (IL) = learn a policy from expert demonstrations $\mathcal{D}=\{(s_i,a_i)\}$. Useful when (a) reward is hard to specify, (b) exploration is dangerous (robotics, driving), (c) we have abundant demonstrations.

11.2 Behavior Cloning (BC)

Supervised learning: train $\pi_\theta(s)\to a$ by minimising loss (cross-entropy / MSE) against expert actions on the dataset.
  • Simple, fast, no environment interaction needed.
  • Compounding errors / covariate shift: tiny mistakes take the agent off the expert distribution, where it has never been trained → cascading failure.

11.3 Inverse Reinforcement Learning (IRL)

Instead of copying actions, learn the reward function the expert is implicitly maximising; then solve the resulting MDP with RL.
  • Approaches: Max-Margin IRL, Max-Entropy IRL (Ziebart 2008), Guided Cost Learning, AIRL.
  • Pros: generalises better than BC (reward is more compact than policy).
  • Cons: ambiguous (many rewards explain the data), expensive (RL in inner loop).

11.4 GAIL — Generative Adversarial Imitation Learning

A GAN-like framework: a discriminator $D$ tries to distinguish expert state-action pairs from those generated by the learner; the policy (generator) is trained with PG using $-\log(1-D)$ as a reward to fool the discriminator. Equivalent to occupancy-measure matching.

Bypasses explicit reward recovery. Strong on continuous control tasks.

11.5 DAgger (Dataset Aggregation, Ross 2011)

Cures BC's covariate shift by iteratively collecting more data on states the learner visits, labelled by the expert.
Initialize π_0 = expert. For i = 1..N: Roll out π_i in env, collect states D_i. Have expert label these states with their action. Aggregate dataset: D ← D ∪ D_i. Train π_{i+1} on D (supervised).

Requires expert to be queryable during training (often a human, simulator, or hand-coded planner).

11.6 Applications

  • Autonomous driving — NVIDIA Dave-2 (BC from human driving), Waymo's chauffeur-net (BC + DAgger).
  • Robotics — DeepMimic (RL with motion-capture as reference), manipulation from teleop demos.
  • Game playing — AlphaStar pre-training on human SC2 replays; Minecraft.
  • RLHF — IL of human preference comparisons drives LLM alignment.

12. Multi-Agent RL (Optional)

12.1 Multi-Agent Environments

A Multi-Agent System has multiple decision-makers each with their own policy. The environment is non-stationary from each agent's perspective because others are also learning.
  • Cooperative — all agents share a reward; goal: maximise common return (e.g. team robots).
  • Competitive — zero-sum (e.g. Go); one's gain is another's loss.
  • Mixed — general-sum (e.g. traffic, ride-sharing).

12.2 Centralized vs Decentralized RL

Centralized TrainingDecentralized Training
What's sharedJoint state, joint rewardEach agent trains alone
ExecutionOften decentralized (CTDE)Decentralized
ProsStable training (no non-stationarity)Scales, privacy
ConsCommunication overheadNon-stationary, less coordination

CTDE (Centralized Training, Decentralized Execution): popular paradigm — train a critic with global info, deploy actors with local observations only. MADDPG, COMA, QMIX, MAPPO.

12.3 Proximal Policy Optimization (PPO)

PPO improves on TRPO with a simpler clipped objective. Let $r_t(\theta)=\frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}$ and $\hat A_t$ the advantage estimate. The clipped surrogate is: $$L^{CLIP}(\theta) = \mathbb{E}_t\!\left[\min\!\bigl(r_t(\theta)\hat A_t,\ \text{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat A_t\bigr)\right]$$ The clip prevents updates from moving the policy too far from $\pi_{\theta_\text{old}}$, ensuring monotonic improvement and stable training without a hard KL constraint.

Typical $\epsilon=0.2$. PPO is on-policy actor-critic; widely used (OpenAI Five, ChatGPT-RLHF, robotics).

12.4 Multi-Agent PPO (MAPPO)

PPO with centralised critic (sees all agents' observations & actions) and decentralised actors. Simple, strong baseline for cooperative tasks (SMAC, GRF).

13. Special Topics (Optional)

13.1 Safe Reinforcement Learning

Constrained RL (CMDP)

MDP plus cost functions; maximise return subject to $\mathbb{E}[\sum c_i] \le \beta_i$. Algorithms: CPO (Constrained Policy Optimization), Lagrangian methods, Reward-Constrained PG.

Safe exploration

Avoid catastrophic states during training (drone crashes, ICU patient harm). Methods: shielded RL (a safety filter overrides unsafe actions), risk-sensitive objectives, action-space pruning.

Adversarial training

Train policies that are robust to perturbed observations, dynamics, or opponent strategies. Domain randomisation; minimax formulations.

Corrigibility

An agent that allows humans to shut it down / correct it without resisting. Active alignment research.

Distributional shift

Train and deployment distributions differ; safety techniques include calibrated uncertainty, conservative Q-learning, ensembles.

Human-in-the-Loop (HITL)

Humans intervene with corrections, preferences (RLHF), or demonstrations. Reduces unsafe exploration and aligns with values.

Formal methods

Use temporal logic, model checking, or reachability analysis to certify safety properties of learned policies.

13.2 Offline / Batch RL

Offline RL learns a policy from a fixed dataset of logged transitions $\mathcal{D}=\{(s,a,r,s')\}$ with no further environment interaction. Critical for medical, recommender, autonomous-driving settings where deployment is risky/expensive.

Key challenge: distributional shift — the learned policy queries actions $\pi(s)$ that are out-of-distribution for $\mathcal D$, making $Q$ estimates unreliable and policies overestimate. Algorithms:

  • BCQ — constrain learned policy near behaviour policy's actions.
  • CQL (Conservative Q-Learning) — penalise Q-values of OOD actions.
  • BEAR, IQL, AWAC — various conservative or constrained methods.
  • Decision Transformer — cast offline RL as conditional sequence modelling.

13.3 Neural Architecture Search (NAS) with RL

  • Zoph & Le 2017 — an RNN controller (policy) proposes child architectures; rewards are validation accuracies after short training; train the controller with REINFORCE.
  • Hugely expensive (thousands of GPU-days); successors (ENAS, DARTS) drop RL or share weights.
  • Frames model design itself as a sequential decision problem — beautiful early application of RL outside games.

Final Cheat-Sheet

  • RL elements: Policy π, Reward R, Value V/Q, Model.
  • Bandit: ε-greedy, UCB $Q+c\sqrt{\ln t/N}$, Gradient bandit (softmax over preferences = SGA).
  • MDP: $\langle S,A,P,R,\gamma\rangle$, Markov property.
  • Return: $G_t=\sum \gamma^k R_{t+k+1}$.
  • Bellman (eval): $v_\pi(s)=\sum_a\pi(a|s)\sum P(s',r|s,a)[r+\gamma v_\pi(s')]$.
  • Bellman optimality: $v_*=\max_a \sum P[\,r+\gamma v_*\,]$.
  • DP: PE + PI; Value Iteration folds max into a single sweep. GPI = any interleaving.
  • MC: average returns, model-free, unbiased, high variance, needs episodes.
  • TD(0): $V\leftarrow V+\alpha[R+\gamma V(S')-V]$.
  • SARSA (on): $Q\leftarrow Q+\alpha[R+\gamma Q(S',A')-Q]$.
  • Q-learning (off): $Q\leftarrow Q+\alpha[R+\gamma\max Q(S',·)-Q]$.
  • Expected SARSA: target = $\mathbb{E}_\pi Q(S',·)$.
  • N-step / Tree backup: trade bias-variance; tree backup is off-policy without IS.
  • Deadly triad: FA + bootstrap + off-policy → divergence. Fixes: target net + replay (DQN).
  • Tile coding: sparse binary features via multiple offset tilings.
  • DQN: replay + target net; loss $(r+\gamma\max Q_{θ-}-Q_θ)^2$.
  • Double DQN: select with online, evaluate with target → fixes overestimation.
  • Rainbow: Double + PER + Dueling + N-step + Distributional + NoisyNets.
  • PG theorem: $\nabla J=\mathbb{E}[\nabla\log\pi(A|S)Q(S,A)]$.
  • REINFORCE: $\theta+=\alpha G_t\nabla\log\pi$. Baseline reduces variance.
  • Actor–Critic: critic gives $\delta$; actor steps with $\delta\nabla\log\pi$.
  • PPO: clipped surrogate $\min(r\hat A,\text{clip}(r,1\pm\epsilon)\hat A)$.
  • MCTS: Selection (UCB) → Expansion → Simulation → Backprop.
  • AlphaGo Zero: single net (p,v) + MCTS, self-play. MuZero: learned latent dynamics. PlaNet: RSSM + CEM.
  • BC: supervised; suffers covariate shift. DAgger: iteratively label learner's states. IRL: recover reward. GAIL: GAN-style imitation.
  • MARL: coop/comp; CTDE; MAPPO with centralised critic.
  • Offline RL: fixed dataset; OOD overestimation. Use BCQ/CQL/IQL.
  • Safe RL: CMDP + Lagrangian, shielding, HITL.
